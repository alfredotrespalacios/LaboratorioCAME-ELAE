# Datos mensuales publicados

Cada país conserva juntos el Parquet, el catálogo Excel y el JSON creados desde
**Mantenimiento de datos**. Reemplace los tres archivos del país en una misma publicación y no
cambie sus nombres.

La aplicación no escribe en GitHub. El ZIP descargado desde Streamlit reproduce la ruta exacta que
debe copiarse al repositorio.

La distribución 1.5.1 incluye como punto de partida la Demanda colombiana aprobada entre enero de
2000 y junio de 2026. El mantenimiento automático puede completar las demás variables sin repetir
esa consulta cuando los tres archivos permanecen publicados juntos.
